# 급식 알레르기 학생 관리 앱 (Vercel 배포용)

요청하신 모든 요구사항이 적용된 최종 버전입니다.

## 📌 주요 반영 기능
1. **페이지 분리 (버튼 전환 방식)**:
   - '학생 정보 등록 페이지'와 '학생 리스트 & 급식 분석 페이지'를 상단 버튼으로 자유롭게 전환 가능
2. **스크롤형 학생 리스트 & 빨간색 강조**:
   - 학년 및 반별 필터링 지원
   - 세로 스크롤 방식의 학생 목록 UI
   - 오늘 급식과 알레르기 충돌 발생 시 해당 학생 카드를 **빨간색(배경 및 테두리)**으로 명확하게 강조
3. **급식 메뉴 텍스트 AI 분석**:
   - 리스트 하단 텍스트 입력창에 급식 메뉴 입력 시 Gemini 2.5 Flash 모델이 알레르기 번호를 인식
4. **Vercel 오류 및 환경 변수 처리 완료**:
   - `package.json` 최신 의존성 및 ES Module(`"type": "module"`) 설정 완료
   - `GEMINI_API_KEY` 환경 변수를 백엔드 서버리스 함수(`api/generate.js`)에서 안전하게 호출

## 🚀 Vercel 배포 가이드
1. 프로젝트를 GitHub에 올리거나 Vercel CLI로 연결합니다.
2. Vercel 대시보드의 `Settings > Environment Variables`에서 `GEMINI_API_KEY` 환경 변수를 추가합니다.
3. 배포가 진행되면 정상 작동합니다.
